# NEON VORTEX

Race through a collapsing dimension before reality tears apart.

## The Game

You're a quantum courier carrying forbidden data through the Vortex—a dying tunnel system between dimensions. The tunnel is collapsing. The walls are breathing. Every turn could be your last.

**Speed that feels dangerous.** You are going too fast. The world is a blur. One mistake and it's over. The music is not background — it IS the game.

## Controls

- **Desktop**: Arrow keys to steer left/right
- **Mobile**: Swipe left/right to steer
- **Both**: Tap to start/restart

## Stages

1. **AWAKENING** - Learn the rhythm
2. **ACCELERANDO** - Things get real
3. **FRACTURE** - Reality starts breaking
4. **COLLAPSE** - Almost too fast
5. **SINGULARITY** - Everything at once

## The Lore

The Vortex was built to transport quantum data between dimensions. It collapsed when someone tried to send consciousness through it. Now it eats ships and spits out their broken signals.

## Built With

- [Three.js](https://threejs.org/) - 3D rendering with bloom post-processing
- [Tone.js](https://tonejs.github.io/) - Music that IS the game
- Vanilla JavaScript (no frameworks)
